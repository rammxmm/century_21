Guía de Instalación y Uso

Cómo abrir y ejecutar el sistema en cualquier computadora sin necesidad de internet ni servidores externos.

Requisitos previos

🖥️ Software necesario

  • Node.js v14 o superior
  • Navegador web moderno
  • Windows / macOS / Linux

📁 Archivos del proyecto

  • Index.html — Página principal
  • login.html — Inicio de sesión
  • App.js — Lógica principal
  • styles.css — Estilos
ℹ️
¿Cómo instalar Node.js?
Descárgalo gratuitamente desde https://nodejs.org → elige la versión LTS → ejecuta el instalador y sigue los pasos. Una vez instalado, reinicia tu computadora.
Pasos para ejecutar
1

Copia la carpeta del proyecto

Transfiere la carpeta completa CENTURY 21 a la nueva computadora mediante USB, red local o cualquier medio. No elimines ni muevas archivos de dentro.

2

Abre una terminal en la carpeta del proyecto

En Windows: navega a la carpeta, haz clic derecho en un espacio vacío y selecciona Abrir en Terminal (o "PowerShell aquí"). En macOS/Linux: usa el comando cd para llegar a la carpeta.

3

Ejecuta el servidor local

Escribe el siguiente comando en la terminal y presiona Enter:

Terminal / PowerShell
# Inicia el servidor (no requiere instalación previa)
npx serve .
4

Abre el sistema en tu navegador

La terminal mostrará una dirección como http://localhost:3000. Abre esa URL en tu navegador. ¡El sistema estará listo para usarse!

⚠️
Nota sobre Firebase: Este proyecto usa Firebase para autenticación y base de datos. Las funciones de login, registro y guardado de datos requieren conexión a internet para conectar con Firebase. El resto de la interfaz funciona sin conexión.

Solución de problemas
❌

La terminal dice "npx no se reconoce"

Node.js no está instalado o no se reinició la computadora después de instalarlo. Instala Node.js desde https://nodejs.org y reinicia.

❌

La página aparece en blanco

Asegúrate de abrir la URL del servidor (localhost:3000) y no el archivo directamente desde el explorador. El file:// no funciona correctamente con este proyecto.

❌

El puerto 3000 ya está en uso

El servidor usará el siguiente puerto disponible (por ejemplo, 3001). Revisa el mensaje en la terminal y usa esa URL.
